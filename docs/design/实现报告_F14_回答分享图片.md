## 7. 发现（不在本次范围内）

1. **`appendMessageFromHistory` 对 assistant 消息无条件设置 `dataset.markdown`**（dom-helpers.ts:493），E-07 的 legacy 降级路径（无 markdown 气泡）在当前代码实际不可达，与复制按钮注释里"legacy bubbles"的说法一样属防御性代码。无需处理。
2. `findUserWrapperBefore`（ui/dom-helpers.ts:390）此前无 ui 层以外调用方通过 feature 引用的先例（错误气泡用它在 services）；本次 feature 复用属合法分层（features→ui）。
3. `side_panel.css` 的操作按钮样式是 3 选择器分组（.tts-btn/.tts-download-btn/.ai-action-btn）；`.share-image-btn` 因不越改动清单在 share.css 独立定义了等值规则。后续若有人调整 side_panel.css 中那组样式，share.css 不会跟随——可考虑合并（本次不做）。
